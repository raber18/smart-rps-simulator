# 「智慧型剪刀石頭布同化模擬器」軟體規格書

## 1. 專案基本資訊與檔案限制
- **專案名稱**：智慧型剪刀石頭布同化模擬器（Smart RPS Ecosystem Simulator）
- **架構限制（嚴格遵守）**：必須輸出為**單一獨立的 HTML 檔案（`index.html`）**。所有 CSS 樣式與 JavaScript 邏輯皆須內嵌於同一檔案中，禁止拆分成外部 `.css`、`.js` 檔，也不得使用任何外部圖片、音效檔案或需要編譯的前端框架（如 React/Vue），確保雙擊檔案或部署至 GitHub Pages 皆可直接離線運作。

## 2. 核心模擬與智慧 AI 行為規則
1. **三陣營與相剋同化規則**：
   - 畫布中存在「剪刀 ✂️（珊瑚紅 `#FF6B6B`）」、「石頭 🪨（岩灰藍 `#4D96FF`）」、「布 📄（薄荷綠 `#6BCB77`）」三種單位。
   - 兩單位發生碰撞時，依相剋關係進行同化：**剪刀同化布、布同化石頭、石頭同化剪刀**（被同化者立即轉換為勝方陣營與顏色）；同陣營碰撞則產生彈性推開，避免重疊卡死。
2. **智慧追逐與閃避機制**：
   - 每個單位具備可調整的「感知半徑」。單位會主動朝感知範圍內最近的「獵物（被自己剋制者）」移動，同時遠離最近的「天敵（剋制自己者）」。
   - 若感知範圍內無其他陣營，則維持帶有微幅隨機擾動的慣性移動；遇到畫布邊界會平滑反彈。
3. **殘局縮圈機制（防止僵局）**：
   - 當單局模擬時間超過 30 秒仍未分出勝負時，戰場邊界將啟動緩慢向內收縮的「紅色安全圈」，迫使剩餘單位向中央集中交戰，確保每局都能順利決出唯一霸主。

## 3. 畫面配置與介面設計
採用現代深色科技風介面（響應式設計，桌面端左右分欄、行動端上下排列）：
1. **頂部戰況儀表板**：
   - 顯示「經過時間（秒）」、「總同化次數」與各陣營即時存活數量。
   - 內建一條動態伸縮的「三色即時兵力佔比長條圖」，直觀呈現三方消長。
2. **中央互動模擬畫布（HTML5 Canvas）**：
   - 深色微網格背景，每個單位以帶有陣營色光暈的圓形徽章搭配清晰圖示繪製。
   - 發生同化瞬間產生擴散波紋粒子特效，並使用瀏覽器內建 **Web Audio API** 合成清脆的「啵」同化音效（右上角提供靜音開關）。
3. **控制與參數設定面板**：
   - **開局預測押寶**：模擬開始前，使用者可點選預測「剪刀 / 石頭 / 布」哪一派會統一全場。
   - **初始數量滑桿**：三組獨立滑桿，分別設定剪刀、石頭、布的初始數量（範圍 5～60，預設各 25）。
   - **物理與模擬參數**：提供「移動速度」、「感知半徑」滑桿，以及「播放倍速切換（1x / 2x / 4x）」。
   - **流程按鈕**：「開始模擬 / 暫停」、「重置戰場」。

## 4. 玩家即時干預（上帝之手互動功能）
模擬進行中，使用者可隨時切換滑鼠點擊模式干預戰局：
1. **空投援軍模式**：選擇「空投剪刀 / 空投石頭 / 空投布」後，點擊畫布任意位置即可在該處生成 3 個該陣營的新單位。
2. **繪製障礙牆模式**：在畫布上按住滑鼠拖曳可畫出實體阻隔線段，單位碰撞牆壁會反彈，藉此改變戰場地形（附「清除所有障礙牆」按鈕）。

## 5. 勝負結算與統計圖表
當畫布上僅剩單一陣營（其餘兩陣營數量皆為 0）時，模擬自動停止並彈出結算視窗，顯示：
- 最終統一全場的霸主陣營、總耗時與總同化次數。
- 開局押寶預測結果（顯示「預測成功！」或「預測失敗」）。
- 使用 Canvas 動態繪製的「三陣營兵力數量隨時間變化折線圖」，並提供「再來一局」按鈕。
